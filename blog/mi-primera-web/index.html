Mi primera web

Una página sencilla para presentarme y una lista de tareas. Mi punto de partida.

Esta web empezó el 12 de septiembre de 2026. Era la primera vez que publicaba algo así.

Qué tenía

  • Una portada con una presentación breve.
  • Una sección de proyectos.
  • Una lista de tareas que guarda los datos en el propio navegador de cada persona.

Cómo estaba hecha

HTML para el contenido, CSS para el diseño y un poco de JavaScript para la lista de tareas. La web se publica gratis con GitHub Pages: cada cambio se propone, se revisa y, al aceptarlo, se publica.
