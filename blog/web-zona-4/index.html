Web para un gimnasio

Hice la web de ZONA 4, un gimnasio inventado en Tenerife, para practicar con un proyecto distinto a mi web.

He hecho mi primera web para un negocio que no es el mío: ZONA 4, un gimnasio inventado en Tenerife. Es práctica para el portfolio.

Qué tiene

  • Portada con vídeo y la próxima clase del día.
  • Clases con foto, horario por días y precios.
  • Mapa con los centros y un botón para buscar el más cercano.

Cómo fue

Probé varias ideas hasta dar con una clara y sencilla. Antes de publicarla revisé errores, móvil, accesibilidad y velocidad, y lo arreglé todo.
